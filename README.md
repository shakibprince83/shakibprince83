## Research beyond the browser

<details>
<summary><b>BioTheraX — Explainable ML for Breast Cancer Treatment Selection</b></summary>

**Unpublished academic research · 2026**

- METABRIC cohort: 1,904 patients, 704 features, and eight treatment categories.
- Pipeline: KNN imputation → consensus feature selection → SMOTE → model benchmarking.
- Best reported experiment: CatBoost with the top 50 features, **89.16% accuracy** and **98.6% AUC-ROC**.
- Built with Python, CatBoost / XGBoost / LightGBM, and SHAP.

</details>

<details>
<summary><b>Automated AWD Rice Irrigation — Multi-Hop LoRa Network</b></summary>

**Unpublished academic research · 2026**

- Ultrasonic sensing with eight-state RTC sleep scheduling.
- Weather-aware, rain-locked pump control.
- Reported **39.4% water savings** and **38.8% energy savings** compared with continuous flooding.
- Built with Arduino, LoRa SX1278, Python / Flask, and Open-Meteo API.

</details>
